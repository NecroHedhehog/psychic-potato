# Linux Scripts

Коллекция bash скриптов для Ubuntu/Debian серверов. Делаю для себя чтобы автоматизировать рутинные задачи администрирования.

Всего утилит: **10 скриптов**

## Скрипты

### [ubuntu-setup.sh](ubuntu-setup.sh)
Основная диагностика системы - показывает состояние сервера одной командой.
- информация о системе и ресурсах
- использование дисков и памяти
- загрузка CPU
- сетевые настройки
- очистка временных файлов

### [check-ports.sh](check-ports.sh)
Проверка открытых портов для контроля безопасности.
- TCP и UDP порты
- активные соединения
- проверка стандартных служб (SSH, HTTP, HTTPS)

### [backup-configs.sh](backup-configs.sh)
Бэкап важных конфигурационных файлов в архив с датой.
- системные конфиги (hosts, hostname, resolv.conf)
- пользовательские настройки (bashrc, profile)
- автоматическое создание tar.gz архива

### [clean-logs.sh](clean-logs.sh)
Очистка старых логов когда заканчивается место на диске.
- журналы systemd (старше 7 дней)
- старые .log файлы (старше 30 дней)
- показывает освобожденное место

### [system-info.sh](system-info.sh)
Краткая сводка о сервере - вся основная информация в одном месте.
- характеристики системы
- ресурсы и загрузка
- диски и сеть
- процессы и активность

### [network-test.sh](network-test.sh)
Проверка сетевого подключения и диагностика проблем.
- локальная конфигурация
- доступность шлюза и DNS
- тест интернет соединения
- простая проверка скорости

### [service-status.sh](service-status.sh)
Проверка состояния системных служб.
- статус основных сервисов (SSH, cron, NetworkManager)
- список проблемных служб
- статистика активных процессов
- последние запущенные службы

### [find-large.sh](find-large.sh)
Поиск больших файлов когда заканчивается место на диске.
- файлы больше 100MB в системе
- самые большие папки в /var
- старые файлы в /tmp
- размер директории с логами

### [disk-usage.sh](disk-usage.sh)
Анализ использования дискового пространства по папкам.
- общее состояние файловых систем
- самые большие папки в корне системы
- использование /home и /var
- свободное место на основном диске

### [process-monitor.sh](process-monitor.sh)
Мониторинг процессов и поиск нагружающих систему задач.
- текущая нагрузка системы
- топ процессов по CPU и памяти
- статистика по пользователям
- процессы работающие дольше суток

## Использование

Все скрипты безопасные - только читают информацию или чистят мусор.

```bash
# скачать конкретный скрипт
wget https://raw.githubusercontent.com/NecroHedhehog/psychic-potato/main/ubuntu-setup.sh

# сделать исполняемым и запустить
chmod +x ubuntu-setup.sh
./ubuntu-setup.sh
```

Права root не нужны для большинства функций.

## Требования

- Ubuntu/Debian Linux
- стандартные утилиты (ss, df, free, journalctl)
